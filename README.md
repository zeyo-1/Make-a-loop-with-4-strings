# ひもの輪 ― 輪はいくつできる？

4本のひも（端は A〜H）を結んだりほどいたりして、できる輪の個数 *N* を確かめる授業用 Web アプリです。
2026年度 一橋大学（前期）数学 第5問をもとにしたワークシート「ひもの輪」と一緒に使うことを想定しています。

**公開ページ：https://zeyo-1.github.io/Make-a-loop-with-4-strings/**

ログインやインストールは不要です。生徒の iPad・スマホでも、プロジェクターに映した先生の画面でも、同じ URL を開くだけで使えます。iPad・iPhone の Safari で「共有 → ホーム画面に追加」をすると、アイコンからすぐ開けます。

## 3つのモード

どのタブも同じ形です。白いカード（作業エリア）に、上から「いま何をするか」→「操作ボタン」→「ひもの図」が並び、輪の数 *N* はいつもカードの右上に出ます。右側（スマホでは下）は記録や表のための場所です。

| モード | できること | ワークシート |
| --- | --- | --- |
| 自由に結ぶ | 端をドラッグして別の端に重ねると結べる（端を2つ続けてタップしても結べる）。結んだ端をタップするとほどける。結ぶたびに輪は円に、つながったひもは円弧に並べ直され、輪の数 *N* がその場で表示される。ひもを指で動かしてからめることもできる（次に結ぶ・ほどくと並べ直される）。 | 問題文・問0 |
| ランダムに結ぶ | 8つの端を無作為に2つずつ結ぶ。1回ずつでも、10回・100回・1000回まとめてでも実演でき、*N* ごとの回数と相対度数を記録する。 | 問0「実演の結果」・問5 |
| 1手ずつ結ぶ | 「まだ結んでいない端のうちアルファベット順で最初の端の相手を決める」を1手ずつ進める。作業カードの上部に「Ⓔの相手をえらぼう」と、相手の候補が「同じひも」「別のひも」のボタンで並ぶ（図の端をタップしてもよい）。右側の3ページ目の図には、何回目に何と何を結んだかと「いまここ」が書き込まれ、問4の表では当てはまる行が光る。 | 問1・問3・問4 |

## 先生用の表示

- 画面右上の「先生用」をオンにすると、文字がプロジェクター向けに大きくなり、「答えを表示」ボタンが出ます。
- 「答えを表示」を押すまで、確率・通り数・期待値などの答えは表示されません（生徒の画面では空欄の枠になります）。答えはワークシートと同じく朱色で表示されます。
- URL の最後に `?teacher=1` をつけて開くと、最初から先生用の表示になります。
  例：`https://zeyo-1.github.io/Make-a-loop-with-4-strings/?teacher=1#random`
- 「ランダムに結ぶ」の先生用表示には「クラスの結果を足す」欄があり、生徒が各自の端末で出した回数を入力して合計できます。

※ 「先生用」のスイッチは生徒の画面にもあります。答えを見られないようにする仕組み（パスワードなど）はありません。

## 記録について

「ランダムに結ぶ」の記録と予想は、その端末のブラウザの中にだけ保存されます。サーバーには何も送りません。「記録を消す」を2回押すと消えます。

## 公開のしくみ

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）がテスト・ビルドをして GitHub Pages に自動で公開します（数分かかります）。進み具合はリポジトリの **Actions** タブで確認できます。

最初の1回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしておく必要があります。

## 内容を変えたいとき

| 変えたいもの | ファイル |
| --- | --- |
| ひもの色・輪の色・端の名前 | `src/logic/strings.ts` |
| 画面の文言・ボタン | `src/modes/FreeMode.tsx`、`src/modes/RandomMode.tsx`、`src/modes/StepMode.tsx` |
| 色・文字の大きさ・レイアウト | `src/styles.css` |
| アイコン | `public/icon.svg`（ホーム画面用の PNG は `public/apple-touch-icon.png` など） |
| ひもの動き（やわらかさ・長さ） | `src/sim/RopeSim.ts` |

GitHub の画面上でファイルを編集して保存（commit）すれば、自動で公開し直されます。

## 手元で動かす（開発する人向け）

Node.js 22 以上が必要です。

```sh
npm ci          # 依存パッケージのインストール
npm run dev     # 開発用サーバー（http://localhost:5173）
npm test        # 105通りの結び方で N=1,2,3,4 が 48, 44, 12, 1 通りになることなどを確認
npm run build   # dist/ に公開用ファイルを作る
```

使っているもの：Vite・React・TypeScript。ひもは SVG で描き、簡単な物理シミュレーション（Verlet 法）で動かしています。
